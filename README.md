🏥 Clinic Call Management Dashboard

A modern, responsive dashboard designed to help clinics manage patient calls, track call activities, and organize follow-ups efficiently. The project aims to improve staff productivity and ensure timely communication with patients.

✨ Features

- 📊 Call Analytics — Track total, answered, missed, and failed calls.
- 🔍 Search & Filters — Find patient call records quickly.
- 📞 Callback Management — Manage patient callbacks efficiently.
- 👤 Patient Details — View call summaries and patient information.
- 🔔 Notifications — Monitor important call updates and activities.
- 📱 Responsive Design — Optimized for desktop and mobile devices.
- 📈 Activity Tracking — Monitor recent calls and call durations.

🎯 Project Purpose

To simplify clinic call management, reduce missed follow-ups, improve communication between clinic staff and patients, and provide an organized view of call activities through a user-friendly interface.
